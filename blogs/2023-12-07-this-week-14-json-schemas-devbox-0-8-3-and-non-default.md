JSON Schemas for Devbox Config and Plugins While we strive to keep the schemas for devbox.json and devbox-plugin.json as simple as possible, it can still be easy to make mistakes when modifying the JSON files directly. To help simplify this, we’ve recently added new JSON Schemas to our main Devbox repo. JSON Schemas can be used to validate or even autocomplete your JSON configs while writing them.
