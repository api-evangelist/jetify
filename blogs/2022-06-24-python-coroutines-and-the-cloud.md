If you commonly use Python, you’ve probably noticed one of the biggest disadvantages of the language, it has no true parallelism. Python’s Global Interpreter Lock (GIL) prevents true parallelism. However, we can achieve a level of concurrency and virtual parallel computing using threads, processes, and/or coroutines.
