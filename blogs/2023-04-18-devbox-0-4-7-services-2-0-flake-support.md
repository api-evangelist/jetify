Devbox 0.4.7 comes with two major new feature requested by users: Services 2.0 , which improves how devbox services works and allows users to define their own custom services Flake Support, which lets users install packages from Nix Flakes hosted on Github, or their own custom flakes Direnv Integration Improvements, which improves the fidelity and performance of our direnv integration. To install the latest version of Devbox, visit our Getting Started guide . If you already have Devbox installed, version 0.4.7 will be pushed to you automatically.
