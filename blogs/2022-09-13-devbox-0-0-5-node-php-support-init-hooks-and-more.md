We're pleased to announce the latest release of Devbox! In addition to various bug fixes and workflow improvements requested by the community, this release focused on adding support for 2 of our most requested languages: NodeJS and PHP. If you already have the Devbox CLI, it should automatically update to 0.0.5 the next time you run it.
