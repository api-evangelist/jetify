We are pleased to announce our end of the year release, Devbox 0.2.0 . This release is one of our biggest yet, packed with features designed to help developers get up and running with Nix based dev environments. Some of the features included in this release are: Automatic Nix Installer : Devbox can now detect if Nix is installed on your machine, and will automatically install it for you if needed.
