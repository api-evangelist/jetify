Devbox 0.8.4: Offline Mode and More We released version 0.8.4 of Devbox last week. In addition to fixing a bug that could potentially prevent Devbox from correctly updating your shell environment, This release added the following features: Offline Mode — Enable developers to reuse their environment if packages are already installed, without requiring a network connection. See below for more insights into how this project works Disable Plugins — The devbox add command now has a --disable-plugin flag, which will install the package without activating it's associated plugin.
